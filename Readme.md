Drone Delivery Simulator

Консольное приложение на языке C, моделирующее работу службы доставки заказов с использованием беспилотников.

Вариант №38 — «Служба доставки беспилотниками».

Возможности

* Моделирование доставки заказов беспилотниками.
* Распределение заказов диспетчером.
* Поиск кратчайших маршрутов алгоритмом BFS с обходом препятствий.
* Учёт грузоподъёмности и запаса энергии беспилотников.
* Зарядные станции с ограниченным количеством мест и очередями.
* Моделирование погодных условий, влияющих на возможность полёта.
* Контроль сроков выполнения заказов.
* Вывод событий симуляции и итоговой статистики.

Требования

* Linux или macOS.
* Компилятор C с поддержкой C11 (Clang).
* Утилита make.

Сборка и запуск

В корневой директории проекта выполните:

make
./fly_simulator

Для удаления результатов сборки:

make clean

Управление

После запуска отображается меню:

========== DRONE DELIVERY SIMULATOR ==========
1. Start simulation
2. Show map
3. Show drones and stations
4. Exit

1. Start simulation — запуск моделирования с выводом событий и итоговой статистики.

2. Show map — отображение карты, склада, препятствий и зарядных станций.

3. Show drones and stations — просмотр информации о беспилотниках, зарядных станциях и заказах.

4. Exit — завершение программы.

Повторный запуск симуляции без перезапуска приложения не предусмотрен.

Принцип работы

Программа использует последовательную событийную имитацию.

Время моделирования разделено на дискретные такты. На каждом такте обновляются погодные условия, проверяются сроки заказов, назначаются доступные беспилотники, выполняются перемещения и обновляется состояние зарядных станций.

Маршруты рассчитываются алгоритмом BFS на прямоугольной карте.

При неблагоприятной погоде полёты приостанавливаются, но зарядка продолжается.

Моделирование выполняется до достижения установленного ограничения по времени.

Настройка симуляции

Исходные параметры задаются в файле src/main.c:

* Размер карты и расположение препятствий.
* Координаты склада и зарядных станций.
* Количество и характеристики беспилотников.
* Параметры заказов и сроки доставки.
* Максимальное время моделирования.

Для изменения сценария необходимо отредактировать соответствующие параметры и пересобрать программу.
